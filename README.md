# FORGE — Performance Training Studio

A fully static, single-page website for a performance training studio. Built with pure HTML, CSS, and vanilla JavaScript — no frameworks, no backend, no build tools.

## Features
- Animated hero with parallax coach cards
- Expandable program sections
- Filterable class schedule
- Multi-step trial booking modal
- Member stories carousel
- Flip-card coach directory
- Testimonial wall
- FAQ accordion
- Sticky booking CTA
- Fully responsive
- Reduced motion support

## Structure
forge/
├── index.html
├── css/
│   └── styles.css
└── js/
    └── main.js

## Usage
Open index.html in any browser. No install needed.
